# Scan&Ready

> **Le téléavertisseur nouvelle génération, sans matériel et sans application.**
> Vos clients scannent, attendent, et sont notifiés quand leur commande est prête.

---

## 📌 À propos

**Scan&Ready** est une application web (et future PWA) de gestion de file d'attente et de notification client pour les cafés, restaurants, boulangeries et tout commerce avec retrait de commande sur place.

Inspiré de solutions existantes comme **Dorakjo** (Jordanie) et **Ayyatli** (Tunisie), Scan&Ready reprend le meilleur des deux mondes :

- **La simplicité d'Ayyatli** : zéro installation, zéro matériel, formation du personnel quasi nulle.
- **La flexibilité de Dorakjo** : intégration avec les systèmes de caisse existants, notifications fiables, avis Google.

### Le problème résolu

Les téléavertisseurs (buzzers) coûtent cher, se perdent, se cassent, tombent en panne de batterie, et le client ne sait pas combien de temps il doit attendre. **Scan&Ready remplace ce matériel par le téléphone du client**, sans qu'il ait besoin d'installer une application.

### Comment ça marche

| Étape | Côté commerçant | Côté client |
|---|---|---|
| **1** | Le caissier saisit le numéro de facture et une durée estimée. | – |
| **2** | Le client scanne le QR code affiché sur le comptoir et entre le même numéro. | Un compte à rebours s'affiche sur son téléphone. |
| **3** | Lorsque la commande est prête, le personnel clique sur « Prêt ». | Le téléphone du client sonne et/ou vibre. |

---

## ✨ Fonctionnalités clés

- ✅ **Aucune application à installer** — tout se fait dans le navigateur du téléphone.
- ✅ **Aucun matériel à acheter** — fonctionne sur tout appareil avec un navigateur.
- ✅ **Minuteur en temps réel** sur le téléphone du client.
- ✅ **Notification « commande prête »** (sonnerie + vibration).
- ✅ **QR code unique** par établissement.
- ✅ **Tableau de bord personnel** simple et intuitif.
- ✅ **Installation en 5 minutes**, formation quasi nulle.
- ✅ **Sans contrat**, résiliable à tout moment.
